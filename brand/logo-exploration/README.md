# Hercules Logo Exploration

This exploration translates the product into a compact visual brief:

- **Product:** a native personal performance system combining workouts, nutrition, measurements, HealthKit, CloudKit, and AI coaching
- **Core idea:** strength becomes useful when it is measured, understood, and sustained
- **Character:** disciplined, calm, intelligent, private
- **Visual language:** minimal geometry, generous negative space, and the existing ink/ivory palette

## Directions

1. **Atlas — recommended:** two grounded pillars and a rising bridge form a distinctive H. It balances strength, progress, and small-size clarity.
2. **Core:** a negative-space H inside a compact circular badge. It is strongest for menu-bar and favicon use.
3. **Cadence:** rounded measurement cells form a modular H. It emphasizes daily logging, routine, and structured data.
4. **Twelve:** twelve rhythmic marks reference both consistency and the mythic twelve labors without using a literal character illustration.
5. **Relay:** connected nodes form a living H. It represents the Mac, iPhone, HealthKit, and AI coaching data loop.
6. **Aegis:** a soft shield contains an upward performance path. It emphasizes privacy, durability, and trusted guidance.

## Files

- `showcase.html` — interactive comparison with light/dark, palette, and size controls
- `overview.svg` — static presentation board
- `01-atlas.svg` through `06-aegis.svg` — editable vector masters using `viewBox="0 0 100 100"` and `currentColor`

No production app assets were replaced. After a direction is selected, the next pass should refine proportions and create the final wordmark, monochrome lockups, transparent PNG exports, and the complete macOS/iOS app-icon set.
